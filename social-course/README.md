西屯婦女培力　08/16（六）09:00–16:00　·　實際授課 6 小時

## 檔案

| 檔案 | 用途 |
| --- | --- |
| `index.html` | **簡報本體**（42 頁，單一檔案、完全離線可用）。用瀏覽器打開就能上課。 |

## 上課時怎麼用

用 Chrome 或 Edge 開啟 `index.html`（Safari 也可以，只是換頁動畫會簡化）。

| 按鍵 | 功能 |
| --- | --- |
| `←` `→` | 上一頁／下一頁（也可以點畫面左右兩側，或用手指左右滑） |
| `S` | **講師備忘**：每頁的講師說明、互動提問、學員實作 |
| `O` | 投影片總覽，點選直接跳頁 |
| `T` | 課堂計時器（可暫停、歸零） |
| `F` | 全螢幕 |
| `P` | 列印／輸出 PDF（選「橫向」，並勾選「背景圖形」） |
| 數字 + `Enter` | 直接跳到某一頁 |
| `?` | 操作說明 |

## 內容結構

42 頁，全程操作導向。三個平台各約 105 分鐘，每一段都走同樣四步：
**建立 → 設定 → 發一次 → 看後台**。

| 時間 | 內容 |
| --- | --- |
| 09:00–09:10 | 開場：今天要做出什麼 |
| 09:10–10:10 | Facebook：建立粉專＋完整設定 |
| 10:20–11:05 | Facebook：發文操作＋後台數據與解讀 |
| 11:05–12:00 | Instagram：建立＋切換專業帳號＋設定 |
| 13:00–13:50 | Instagram：發文／限動／Reels＋洞察與解讀 |
| 13:50–14:25 | LINE：建立官方帳號＋基本設定 |
| 14:35–15:45 | LINE：歡迎訊息／群發／圖文選單＋後台解讀 |
| 15:45–16:00 | 三個帳號總檢查＋回家怎麼做 |

42 頁裡有 29 頁標記了實作提示（右上角顯示「手機實作／成果確認／一起判讀」等）。
每個平台都包含「後台在哪 → 看懂四個數字 → 三種情況怎麼調整」三頁。

## 上課前要準備的三件事

1. **講師手機要能投影**。整份簡報是「跟著做」的節奏，沒有投影會很難進行。
2. **確認三個 App 的介面版本**。FB／IG 常改版，簡報裡的手機示意圖是通用版；
   建議上課前一天用自己的手機走一次流程，若選單文字不同，現場改用學員手機投影。
3. **準備 1–2 位助教**在教室走動。80% 的學員只會手機基本功能，一定會有人卡住。

## 改內容

```bash
cd social-course
# 改 src/slides-a.js（封面～Slide 34）或 src/slides-b.js（Slide 35～結尾）
python3 build.py        # 重新產生 index.html
```

- `src/styles.css` — 視覺系統（色票、字級、卡片、手機模擬介面）
- `src/art.js` — 插畫與介面示意圖庫（全部是內嵌 SVG，不依賴外部圖片）
- `src/engine.js` — 翻頁、轉場、總覽、備忘、計時器、列印
- `src/shell.html` — HTML 外框與佔位符

每一則投影片的格式：

```js
S({ part:'PART 5', time:'13:28', kind:'std', title:'Slide 31｜一個商品，三種呈現',
    html:`…`,
    notes:{ say:[...], ask:[...], do:[...] },   // 按 S 顯示
    tag:{ type:'do', label:'講義 4' } });        // 右上角提示（可省略）
```

## 設計說明

- 固定 1280×720 舞台等比縮放，任何投影機上版面都不會跑掉。
- 轉場使用 View Transitions API 的緩慢溶解＋微縮放，
  搭配頁內元素依序浮現；不使用翻頁、旋轉、飛入等效果。
  瀏覽器不支援時自動退回柔和淡入，並尊重「減少動態效果」的系統設定。
- 全部圖像都是內嵌 SVG 或 CSS 繪製，**不連外**，教室沒網路也能正常上課。

## 匯出 PPTX（給 PowerPoint 或 Canva）

```bash
node export-canva.js          # 先產生靜態版面
node export-pptx/extract.mjs  # 量測版面，拆成 shape / image / text
node export-pptx/build.js     # 組出 social-media-course-deck.pptx
node export-pptx/preview.js   # 選用：產生 preview.html 檢查組成結果
```

匯出的 PPTX 不是一張張圖片，而是三種可編輯物件：

| 物件 | 數量 | 在 PowerPoint／Canva 裡可以做什麼 |
| --- | --- | --- |
| 文字框 | 1,220 | 改字、改色、改大小（全部 ≥ 15pt） |
| 圖形 | 664 | 卡片、色塊、標籤、進度條——可改填色、框線、大小 |
| 圖片 | 252 | 插畫、手機介面、貼文卡——可移動、縮放、刪除、替換 |

底圖只保留漸層與 CSS 裝飾線，其餘都是獨立物件。

`extract.mjs` 會在量測前先把小於 20px（15pt）的文字放大，讓整頁重新排版，
因此文字框位置與背景圖取自同一個排版狀態，不會對不上。
手機介面、貼文卡與第 33 頁「刻意做得看不清楚的傳單」標記為整塊圖片，不受字級下限影響。
