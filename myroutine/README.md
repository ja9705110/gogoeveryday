# MyRoutine 我的例行程序 📱

仿 MyRoutine 的每日例行程序／習慣養成手機 App（PWA），純前端、免安裝、離線可用。

## 怎麼在手機上使用

1. 把這個 repo 開啟 GitHub Pages（Settings → Pages → 選擇分支），
   然後在手機瀏覽器打開 `https://<你的帳號>.github.io/<repo名稱>/myroutine/`
2. **加入主畫面**：
   - iPhone（Safari）：分享 → 「加入主畫面」
   - Android（Chrome）：選單 → 「安裝應用程式」或「加入主畫面」
3. 之後從主畫面圖示開啟，就是全螢幕、可離線使用的 App

## 功能

- 🏠 **今日**：顯示今天排定的例行程序、完成進度、連續天數 🔥
- ▶️ **執行模式**：逐項任務倒數計時（圓形進度環、暫停、+30 秒、跳下一項、提示音＋震動）
- 📋 **例行程序管理**：自訂名稱、圖示、顏色、星期幾重複、每項任務時長，可排序
- 📊 **統計**：目前／最佳連續天數、累計完成次數、近 7 天長條圖、本月月曆熱力圖
- ⚙️ **設定**：深色模式、提示音開關、JSON 匯出／匯入備份、清除資料

## 檔案

| 檔案 | 說明 |
|---|---|
| `index.html` | 整個 App（HTML + CSS + JS 單一檔案） |
| `manifest.webmanifest` | PWA 設定（加入主畫面用） |
| `sw.js` | Service Worker（離線快取） |
| `icon-192.png` / `icon-512.png` | App 圖示 |

資料全部儲存在裝置的 localStorage，不會上傳到任何伺服器。
